# Emily Hedegard — Portfolio

Personal investigative-journalism portfolio, built as static HTML/CSS and deployed via GitHub Pages.

## Structure
- `index.html` — home
- `investigations.html` — full investigation cards
- `features.html` — features & essays
- `archive.html` — complete chronological archive
- `about.html` — bio
- `contact.html` — contact info
- `css/style.css` — shared styles
- `images/` — headshot and other media

## Editing
Each page is plain HTML — open any file, edit the text or links directly, and push to update the live site (Pages redeploys automatically on push to `main`).

To swap in real outlet logos, replace the `.outlet-badge` text spans in `index.html` with `<img>` tags pointing at logo files added to `images/`.
